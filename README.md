# Settimana

Cerniera's calendar as a paper diary's week to view, for the Galaxy Z Fold 8 Ultra. Open, the crease is the binding: Monday to Wednesday on one page, Thursday to Sunday on the other; busy days swell and quiet ones give way. Nodo's knots sit in each day's margin. Version one reads the phone's calendars and hands new events to the calendar app.

Built on the Cerniera Kit (`kit`, a git submodule). Every push builds an APK, runs the week logic tests and walks the four shapes on an emulator; the APK and screenshots are attached to the build's release.
